# 📝 To-Do List App

A simple and interactive **To-Do List Application** built using **Core HTML, CSS, and JavaScript**.

This project allows users to manage their daily tasks efficiently with features like adding, editing, deleting, and marking tasks as complete.

## ⚙ How It Works

### ➕ Add Task
- Enter task in input field
- Click "Add" button
- Task appears in the list

### ✏ Edit Task
- Click edit button next to task
- Modify text
- Save updated task

### 🗑 Delete Task
- Click delete button
- Task is permanently removed

### ✅ Mark as Complete
- Click checkbox
- Task gets strike-through style
- Indicates completion
